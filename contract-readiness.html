Contract readiness

Test the contract before you market it.

This checklist explains the fixed-supply ERC-20 package in this repo and what Elliott must confirm before deployment, verification, and promotion.

Repo package

Contract

`contracts/Tollahcoin.sol` defines the starter OpenZeppelin ERC-20.

Tests

`test/Tollahcoin.t.sol` checks metadata, fixed supply, no-tax transfers, and zero treasury rejection.

ABI check

`scripts/verify-abi.js` rejects unexpected mint, pause, blacklist, or fee setter functions.

Deploy tools

`scripts/deploy-polygon.js` deploys with Elliott's treasury wallet, then `scripts/update-site-after-deploy.js` updates public links.

Intended token properties

Fixed supply1,000,000,000 IRAN
Decimals18
Buy / sell tax0% / 0%
Extra mintingNo owner-only mint function
Transfer controlsNo pause or blacklist function
TreasuryInitial supply goes to constructor treasury address

Before deployment

1. Choose treasury

Pick the wallet that receives the full initial supply and keep it separate from unrelated personal funds.

2. Run tests

Run `npm test` and keep the passing output with the deployment records.

3. Verify source

Verify on PolygonScan with Solidity `0.8.28`, optimizer enabled, and `200` optimizer runs.

4. Update site

Run `npm run update:site:contract` after deployment and PolygonScan verification.

Records to keep

Save deployer address, treasury address, network, contract address, transaction hash, and exact commit hash. Do not claim deployed, verified, no-tax, fixed-supply, or exchange-ready status until live links prove it.

Contract facts must match the deployed and verified Polygon contract.
